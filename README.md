# Admin Limão Azedo — V1

Painel administrativo separado do Portal do Cliente.

## Recursos iniciais

- Login administrativo;
- pesquisa por Curral e Carimbo;
- atualização dos dados principais do lote;
- registro de tratamento;
- histórico sanitário;
- interface para celular e computador;
- preparação para PWA.

## Variáveis que serão cadastradas na Cloudflare

- APPS_SCRIPT_URL
- API_SECRET
- ADMIN_USER
- ADMIN_PASSWORD
- ADMIN_TOKEN_SECRET

Não coloque senhas dentro do GitHub.
